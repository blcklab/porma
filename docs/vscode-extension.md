# VS Code extension

**Porma BLCK** adds editor support for `.blck` components.

Features:

- Syntax highlighting for `<logic>`, `<view>`, and `<style scoped>`
- TypeScript highlighting in `<logic lang="ts">`
- Highlighting for Porma directives and events
- Snippets for common component patterns

Install the extension from the VS Code Marketplace, then open any `.blck` file.
