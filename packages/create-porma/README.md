# create-porma

Create a new Porma app.

```bash
npm create porma@latest my-app
```

Choose a template:

```bash
npm create porma@latest my-app -- --template basic
npm create porma@latest my-app -- --template typescript
npm create porma@latest my-app -- --template router
```

Then start the app:

```bash
cd my-app
npm install
npm run dev
```
